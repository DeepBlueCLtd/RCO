VAL — Vault Asset Log

Hosted demo, pull request previews and test coverage

Welcome

VAL is a secure asset register: it tracks media items, batches, projects, vault locations, loans, dispatch and destruction, with role-based access and a full audit log. The source is on GitHub.

The versions on this site run entirely in your browser: an in-memory copy of the development database stands in for the server. Nothing you enter leaves your browser, and the data is reset each time the page is reloaded.
